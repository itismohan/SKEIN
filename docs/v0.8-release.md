# Skein v0.8 Release Notes

v0.8.0 introduces Adaptive Context Intelligence.

### Included
- Deterministic graph-evidence ranking.
- Token-budgeted greedy context selection.
- Evidence-type diversity during selection.
- Explicit bounded relevance feedback.
- Persistent context selection and feedback ledgers.
- CLI selection, rendering, feedback and health commands.
- Unit coverage for budget enforcement, relevance and adaptation.

### Compatibility
- Software version: `0.8.0`.
- Graph contract remains independently versioned at `1.0.0`.
- Existing v0.7 agent adapters and provider bridges remain available.

### Limitation
v0.8 proves the adaptive retrieval control loop locally. It does not claim production LLM quality improvement until paired real-agent experiments from the v0.6 control plane provide sufficient evidence.
