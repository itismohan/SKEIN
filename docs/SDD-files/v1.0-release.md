# Skein v1.0 Release

v1.0 establishes the AI-DLC Control Plane over the capabilities introduced from v0.1 through v0.9.

## Acceptance criteria

- Governed lifecycle state machine with invalid-transition protection.
- Persistent run state and append-only lifecycle events.
- Explicit quality evidence separated from agent/provider success.
- Explicit human approval gate.
- Deterministic export integrity fingerprint.
- CLI lifecycle operations.
- Backward-compatible graph schema v1.0.0.
- Existing SDD, MCP, telemetry, adaptive context, provider bridges, and autonomous quality-loop gates remain intact.

## Non-goals

v1.0 does not silently modify repositories, grant network privileges, claim autonomous correctness from model output, or replace existing policy/sandbox controls.
