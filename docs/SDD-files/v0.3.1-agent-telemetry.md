# Skein v0.3.1 — Real Agent Telemetry Adapter

v0.3.1 closes the measurement gap between the deterministic pilot harness and real agent/provider traffic.

## Normalized event contract

External runners emit JSONL records with:

- `event_id`, `experiment`, `task_id`, `agent`, `timestamp`
- `input_tokens`, `output_tokens`, optional `reasoning_tokens`
- optional `estimated_cost_usd`, `latency_ms`, `outcome`
- optional `handoff_from`, `handoff_to`
- arbitrary `metadata`

`experiment` must be `baseline` or `skein`.

## Import

```text
skein telemetry-import . pilot-events.jsonl
skein pilot-task-summary .
skein pilot-intelligence-run .
```

The importer validates required fields, rejects duplicate event IDs within the source, and writes normalized events to the append-only Skein telemetry store. Provider-specific SDKs remain outside the core so the pilot protocol is provider-neutral.

## Evidence model

Task IDs allow multiple agent calls to be correlated into a single engineering task. This enables cost-per-task, token-per-task, agent-count, error, and handoff measurements while preserving the existing conservative `NOT_MEASURED` boundary.

This adapter does not claim that process completion equals task success. Human-reviewed task outcomes remain authoritative for quality claims.
