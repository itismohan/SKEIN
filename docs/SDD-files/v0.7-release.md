# Skein v0.7 Release

## Theme

**Real Agent Execution & Pilot**

v0.7 turns Skein's experimental protocol into a controlled execution path for real command-line agents.

## Included

- explicit argv execution with `shell=False`
- experiment-assignment enforcement
- Baseline and Skein context envelopes
- execution telemetry and connector events
- task/context/command fingerprints
- timeout and process-failure capture
- evaluation-compatible task results
- execution status CLI

## Validation standard

The release must pass the full test suite, release gates, hardening checks, and MVP acceptance. The release itself does not constitute empirical evidence of Skein effectiveness.
