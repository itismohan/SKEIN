# Skein v0.6 Release

## Experimental Control Plane

v0.6 adds reproducible experiment design around the existing graph, traceability, telemetry, connector and evaluation layers.

### Release gates

1. v0.6 control-plane module and tests pass.
2. Task registration rejects duplicate IDs.
3. Seeded assignment is deterministic.
4. Assignment/task corpus mismatch is detected.
5. Environment and study fingerprints are recorded.
6. Manifest tampering is detected.
7. Power guidance is explicitly labeled planning guidance.
8. Existing v0.5 evaluation remains unchanged and continues to distinguish evidence from insufficient evidence.

### Non-goals

- No arbitrary agent execution.
- No fabricated experimental outcomes.
- No claim that local randomization establishes production causality.
- No silent outlier deletion.

### Upgrade

The software package moves from `0.5.x` to `0.6.0`. The graph contract remains independently versioned at `1.0.0`.
