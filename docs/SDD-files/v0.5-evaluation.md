# Skein v0.5 — Agent Evaluation & Evidence Engine

Skein v0.5 converts matched baseline/Skein task evidence into conservative statistical findings.

## Design goals

- Never infer missing measurements.
- Compare matched tasks rather than unrelated aggregate runs.
- Report sample size and uncertainty.
- Use deterministic bootstrap confidence intervals for reproducible CI evidence.
- Separate statistical support from causal claims.
- Protect task success as a guardrail while evaluating efficiency.

## Commands

```text
skein evaluation-init .
skein evaluate .
skein evaluation-report .
```

## Evidence model

For each metric, v0.5 reports baseline mean/median, Skein mean/median, improvement percentage, paired mean improvement, bootstrap confidence interval, sample size, and whether the configured threshold is met.

Default statistical gate: at least 10 matched tasks and a 95% bootstrap interval for the improvement that remains above zero.

The default success guardrail permits at most a 2 percentage-point degradation. This is a guardrail, not proof of equivalence.

## Evidence grades

- **A** — 30+ matched tasks, supported improvement, success guardrail passes.
- **B** — 10+ matched tasks, supported improvement, success guardrail passes.
- **C** — paired evidence exists but does not satisfy the full statistical gate.
- **D** — no matched evidence.

## Interpretation

The engine reports statistical support, not causality. A design-partner experiment should randomize or counterbalance task assignment where practical, pre-register primary metrics, preserve raw event evidence, and avoid changing evaluation criteria after seeing results.
