# Skein v0.5.0 Release

## Agent Evaluation & Evidence Engine

Skein v0.5 adds a statistically disciplined evaluation layer on top of connector and Pilot Intelligence evidence. It compares matched baseline/Skein tasks and reports effect size, uncertainty, sample size, success guardrails, and an evidence grade.

### What is new

- Deterministic bootstrap confidence intervals.
- Matched-task evaluation instead of unpaired aggregates.
- Efficiency metrics: context tokens, cost, latency.
- Quality metrics: rework and handoff loss.
- Task-success guardrail.
- Evidence grades A/B/C/D.
- Explicit `SUPPORTED` vs `INSUFFICIENT_EVIDENCE` claim status.
- CLI commands for evaluation initialization, execution, and reporting.

### Commands

```bash
skein evaluation-init .
skein evaluate .
skein evaluation-report .
```

### Evidence policy

A positive metric is statistically supported only when the configured minimum matched-task count is reached and its deterministic bootstrap confidence interval remains above zero. This is evidence of an observed paired improvement, not proof of causality. Real design-partner studies should randomize/counterbalance tasks where practical and preserve raw telemetry.

### Current local status

The repository contains no real paired design-partner task corpus, so the release deliberately reports **evidence grade D / insufficient evidence** for the current workspace. This is expected and prevents benchmark machinery from being mistaken for customer evidence.
