# Skein v0.7 — Real Agent Execution

## Purpose

v0.7 closes the loop between the v0.6 Experimental Control Plane and actual agent runs. It provides a provider-neutral, controlled CLI execution harness that can run an explicitly supplied agent command under a randomized Baseline/Skein assignment and capture execution telemetry.

## Safety boundary

The runtime accepts an explicit JSON argv array and always uses `shell=False`. It does not interpret shell syntax, discover arbitrary commands, or grant network permissions. The caller is responsible for the agent executable and its sandbox/container policy.

## Execution model

```text
Experiment assignment
        |
        v
Task + assigned arm
        |
   +----+----+
   |         |
Baseline   Skein
   |         |
   +----+----+
        |
  explicit argv agent
        |
  execution telemetry
        |
  v0.5 evaluation
```

For the Skein arm, the runtime builds a task/context envelope from `.skein/graph.json`. For the Baseline arm, the task description is the context. The context and task are fingerprinted for reproducibility.

## CLI

```bash
skein agent-run . \
  --task-id T1 \
  --arm baseline \
  --command-json '["python","agent.py"]'

skein agent-run . \
  --task-id T2 \
  --arm skein \
  --command-json '["python","agent.py"]' \
  --context-query 'what calls checkout?'

skein agent-status .
```

The command receives:

- `SKEIN_TASK_ID`
- `SKEIN_EXPERIMENT_ARM`
- `SKEIN_CONTEXT_MODE`
- `SKEIN_TASK_DESCRIPTION`
- `SKEIN_CONTEXT`
- `SKEIN_TASK_CONTEXT_JSON`

## Evidence captured

Each execution records exit status, outcome, latency, task/context token counts, stdout/stderr sizes, timeout state, command fingerprint, task fingerprint, and context fingerprint. A normalized connector event is also written so existing telemetry and evaluation pipelines can consume the run.

## What v0.7 does not claim

A successful execution is not proof that Skein improves engineering outcomes. Real claims require matched Baseline/Skein tasks, valid randomization, sufficient sample size, appropriate statistical analysis, and task-success guardrails.
