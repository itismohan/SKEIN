# Skein v0.9 Release

Skein v0.9 introduces the Autonomous Quality Loop.

### New

- Bounded autonomous quality-loop controller
- Provider-neutral agent execution through existing adapters
- Pluggable engineering-quality evaluator
- Automatic context feedback from observed quality outcomes
- Retry with newly ranked adaptive context
- Append-only quality-loop evidence ledger
- Quality-loop CLI and status command
- v0.9 documentation and release contract

### Positioning

v0.7 established controlled execution. v0.8 made context adaptive. v0.9 closes the loop by connecting execution outcomes back into context selection.

### Limitations

The default evaluator measures execution outcome only. Production deployments should supply validators such as unit/integration tests, contract checks, static analysis, security scanning, acceptance criteria, or human approval depending on risk.
