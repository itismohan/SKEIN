# Skein Stage 6 — Hardening, Packaging & Release Plan

Stage 6 is the final productization increment. The implementation is intentionally separated from Stage 5 so registry publication and pilot claims are not confused with local MVP functionality.

## Remaining release gates

1. Quickstart verified on a clean environment in under 10 minutes.
2. Complete graph schema and MCP references published.
3. Migration guide for standalone graph/compression users.
4. Independent software/schema semantic versioning and deprecation policy.
5. PyPI/npm/skill packaging validated; publication is a release operation, not an offline test claim.
6. Closed design-partner pilot with real repositories and six-pager metrics.
7. Production monitoring for graph-store health, MCP uptime, and sampled compression verification.
8. Dedicated feedback path for compression false negatives and EXTRACTED/INFERRED mis-tagging.

## Current MVP release artifact

The repository can be distributed as a source ZIP. Registry publication and design-partner pilot are intentionally not represented as complete until externally executed and measured.
