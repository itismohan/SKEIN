# @skein-ai/mcp-protocol

Interoperability metadata and schemas for Skein MCP integrations.

This package is intentionally dependency-free. It does not run the Skein server; it provides the protocol manifest/schema that client adapters can validate before connecting to a Skein MCP endpoint.

## Versioning

Package version `0.3.0` tracks the Skein software release. The graph contract remains independently versioned at `1.0.0`.
